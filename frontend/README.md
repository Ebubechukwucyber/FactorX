# FactorX Frontend

Institutional Passport dashboard for the Commercial Cashflow Passport.

## Design
- Deep charcoal background
- Large central passport score
- Restrained emerald accent
- Clean typography, generous spacing
- No generic neon Web3 styling

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- wagmi / viem ready (wallet connection next)

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
